# Automatic Git Commit & Push Rule

Whenever any code modification, feature addition, bug fix, or design adjustment is completed in this project:
1. Always stage the modified files (`git add .`).
2. Commit with a clear, concise, and descriptive commit message (`git commit -m "..."`).
3. Automatically push the commit to GitHub (`git push origin main`).
4. Never leave completed edits unpushed unless the user specifically asks to pause or keep local changes.
